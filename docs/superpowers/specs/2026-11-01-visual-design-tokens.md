# 视觉设计规范（暗色工业质感）

- 日期：2026-11-01
- 状态：已实现
- 前置：`2026-10-24-chatgpt-iq-radar-design-v2.md`
- 令牌实现：`src/styles/tokens.css`

## 0. 为什么要有这份文档

v2 设计规格 §7.1 关于视觉的全部内容只有一行：

> 样式：CSS 变量 + 原生 CSS；深浅色主题；响应式断点。

**没有一个色值、没有一条字阶、没有圆角与间距刻度、没有参考对象。** 文档层不定义视觉，实现层就只能交「能跑就行」的结果：首版 `theme.css` 全文 90 行，审阅 UI 的只有 `button { font: inherit }` 和 `th,td { padding }` 两条，构建产物 CSS 2.5 KB，控件全是浏览器原生外观。

这份文档补的就是那层缺失：色板、字阶、间距、圆角、阴影、动效全部定死成令牌，组件只许引用令牌。

## 1. 方向

暗色工业质感，语汇取自 Linear / Vercel 类仪表盘：近黑墨蓝底、单一哑光香槟金强调、细字重宽字距标题、等宽数字严格右对齐、发丝边框与顶部内高光。

亮色主题是同构对偶，不是「把暗色调亮」：强调色反向压深到 5:1，语义色换更深色相，阴影改浅扩散。

**不采用**毛玻璃 / backdrop-filter：34 格矩阵与宽表格数据密度高，实色背景 + 发丝边比半透明层叠清楚。

## 2. 色板

| 令牌 | 暗色 | 亮色 | 用途 |
| --- | --- | --- | --- |
| `--bg-base` | `#08090C` | `#FBFBFC` | 页面底 |
| `--bg-raised` | `#0E1015` | `#FFFFFF` | 卡片 |
| `--bg-overlay` | `#14171F` | `#F4F5F7` | 悬浮层 / 输入 |
| `--line-hair` | `rgba(255,255,255,.06)` | `rgba(9,12,20,.07)` | 结构分割 |
| `--line` | `rgba(255,255,255,.13)` | `rgba(9,12,20,.14)` | 控件描边 |
| `--fg` | `#E9EAEE` | `#14161A` | 正文 |
| `--fg-muted` | `#98A0AD` | `#59606D` | 次要 |
| `--brass` | `#C9A96B` | `#8A6A2C` | 唯一强调色 |
| `--up` | `#6FC79B` | `#12724B` | 上升 |
| `--down` | `#E28C7C` | `#A3301F` | 下降 / 告警 |

规则：

- 强调色只有「可交互」与「当前态」两处用，用多了就廉价。
- 语义色一律降饱和，鲜红鲜绿在 34 格矩阵里互相打架且过不了对比度。
- 分档底色只到 `rgba(...,.12~.15)` 量级，强度靠左侧 3px 竖条承担。

## 3. 对比度预算（WCAG 2.2 AA）

正文 4.5:1、大字与图形 3:1。取值时已算过，实测余量：

| 组合 | 暗色 | 亮色 |
| --- | --- | --- |
| 正文 / 底 | 16.5:1 | 17.9:1 |
| 次要 / 底 | 7.6:1 | 5.9:1 |
| 强调 / 底 | 9.1:1 | 5.0:1 |
| 上升 / 底 | 10.5:1 | 5.3:1 |
| 下降 / 底 | 7.9:1 | 6.3:1 |

收紧任何一档前先复算。`tests/a11y.test.tsx` 的 axe 闸门会拦 critical / serious 违规。

## 4. 字体

自托管，`src/styles/fonts/` 存 woff2，`@font-face` 在 `tokens.css` 顶部。

**为什么自托管**：实测本机到 `fonts.googleapis.com` / `fonts.gstatic.com` 直连超时（IPv4 / IPv6 均 ETIMEDOUT），外链会让首屏白等 20s+ 再回落。自托管后 e2e 耗时从 43s 降到 13s。

| 族 | 字重 | 用在哪 |
| --- | --- | --- |
| Inter（latin 子集） | 400 / 500 / 600 | 全部 Latin 与正文 |
| JetBrains Mono（latin 子集） | 400 / 500 | 分数、耗时、成本、时间、模型名 |

中文不进字体包，一律回落 `PingFang SC` / `Microsoft YaHei`。

**所有数字强制 `font-variant-numeric: tabular-nums`，数字列右对齐。** 这是数据看板可读性的地基——比例数字会让 34 格矩阵纵向错位。

## 5. 字阶与间距

字阶：`--fs-display`（clamp 28→40px，负字距 `-.02em`）/ `--fs-h2` 19px / `--fs-h3` 15px / `--fs-body` 14px / `--fs-sm` 12.5px / `--fs-label` 11px（大写 + 字距 `.1em`）。

间距 4px 基准八档 `--sp-1..--sp-12`。组件内边距只用 1–4 档，区块间距才用 6 档以上。

圆角收紧到上限 8px（`--r-sm` 3 / `--r-md` 5 / `--r-lg` 8），不用 12px 以上。

## 6. 组件规范

- **按钮**：默认透明底 + 发丝描边（`.btn-ghost`），hover 提亮描边与底色，active 下沉。
- **分段控件**（tab）：贴底线，选中项 brass 短下划线 + 自带底色；hover 不叠第二层。
- **复选项**（`.chip`）：整块可点，选中转 brass 描边 + 极淡晕；只有不可选才降透明并转虚线边。
- **矩阵格**：左 3px 竖条编码强度，选中用 brass 双环 + 外晕，hover 上浮 1px。
- **表格**：只留横向发丝线，表头小字大写，数字列右对齐等宽，行 hover 微提亮。
- **卡片**：实色抬升 + 发丝边 + 顶部内高光，不用描黑边。
- **焦点环**：`2px solid var(--brass)` + `3px` offset + 外晕，全站唯一必须显眼的装饰。

## 7. 动效

只做交互反馈，不做入场动画。120ms / 200ms，缓动 `cubic-bezier(.2,.6,.3,1)`。`prefers-reduced-motion: reduce` 下全部压到 1ms 并关掉位移。

## 8. 约束

- 组件不写裸十六进制，一律引用令牌。
- 语义类名 `card` / `muted` / `down` / `up` / `warn` / `sr-only` / `table-wrap` / `skip-link` 被测试直接断言，不许改名。
- 网格容器（`main`、`[role="tabpanel"]`）必须显式 `grid-template-columns: minmax(0, 1fr)`，否则隐式 `auto` 列会按宽表格的 max-content 撑破整页。
- 新增外部资源前先验证连通性；不可达就走自托管。
